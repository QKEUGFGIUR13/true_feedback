True Feedback

True Feedback is an anonymous feedback platform built using Next.js that allows users to receive anonymous messages with secure authentication and AI-powered question suggestions.

👨‍💻 Author

Nihal Anand

🛠 Tech Stack
Frontend: Next.js 15, React Hook Form, ShadCN UI, Aceternity UI, TailwindCSS, Framer Motion
Backend: Next.js API Routes, MongoDB
Authentication: NextAuth/Auth.js with JWT (Credentials Provider)
Email Verification: Brevo (OTP-based verification)
AI-powered Suggestions: Google Gemini API (gemini-2.5-flash), Vercel AI SDK v5 (streamText)
Database Operations: MongoDB Aggregation Pipeline
Debouncing: Custom debouncing for username availability checks
✨ Key Features
🔐 Secure JWT-based authentication system
💬 Anonymous messaging functionality
🤖 AI-generated question suggestions using Google Gemini
📧 OTP-based email verification using Brevo
🎨 Modern responsive UI with ShadCN UI and Aceternity UI
⚡ Real-time AI response streaming with Vercel AI SDK
🔍 Real-time username availability validation with debouncing
📊 Optimized MongoDB aggregation queries
🌓 Fully responsive design across devices
🎭 Smooth animations using Framer Motion
🎯 Project Description

Developed a full-stack anonymous feedback platform using Next.js 15, MongoDB, and NextAuth with JWT authentication. Integrated Google Gemini AI for generating dynamic anonymous question suggestions with real-time streaming using Vercel AI SDK. Implemented OTP-based email verification using Brevo, responsive UI with TailwindCSS, ShadCN UI, and Aceternity UI, along with optimized backend APIs and MongoDB aggregation pipelines for efficient data handling.
